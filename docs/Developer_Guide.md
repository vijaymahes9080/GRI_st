# Enterprise Specification: Android Developer Guide

## 1. Local Android Environment Onboarding
- **Node.js**: `v20.x LTS`
- **Android Studio**: Android SDK 34 (Android 14) + Android Virtual Device (AVD) / Physical Device with USB Debugging enabled.
- **Expo CLI**: `npm install -g expo-cli`

---

## 2. Command Reference

```bash
# Install dependencies
npm install

# Start Expo bundler
npm start

# Run directly on connected Android device / emulator
npm run android

# Execute TypeScript typechecking
npm run typecheck

# Run Jest tests
npm test
```
